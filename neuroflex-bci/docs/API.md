# Device API Reference

Base URL (local dev): `http://localhost:8000`

The API is the contract between the implanted-device bridge and the
companion mobile app. In this reference implementation it holds simulated
in-memory device state (see `neuroflex/api/main.py`); a production
deployment would back this with a real device bridge/gateway and a
persistent, access-controlled data store.

Interactive docs are auto-generated by FastAPI at `/docs` (Swagger UI) and
`/redoc` when the server is running.

## Authentication

Not implemented in this reference version. A production deployment must
add per-patient/clinician authentication and authorization (e.g. OAuth2 +
mTLS on the device bridge link) before this API is exposed outside a
trusted network — see `docs/compliance/CYBERSECURITY.md`.

## Endpoints

### `GET /health`
Liveness check.

### `GET /v1/devices/{patient_id}/status`
Returns current device status: connection state, battery, charging state,
last calibration timestamp and validity, current committed grip, decoder
confidence, and whether a safety interlock is currently tripped.

### `POST /v1/devices/{patient_id}/mode`
Switch operating mode. Body:
```json
{ "patient_id": "P-1002", "mode": "assisted" }
```
`mode` ∈ `assisted | manual_override | locked`.

### `POST /v1/devices/{patient_id}/lockout`
Immediately engage or release the manual safety lockout (see `SafetyInterlock.MANUAL_LOCKOUT`).
```json
{ "patient_id": "P-1002", "locked": true, "reason": "clinician request" }
```

### `POST /v1/devices/{patient_id}/calibration/start`
Kick off a guided calibration session.
```json
{ "patient_id": "P-1002", "cue_sequence": ["power", "pinch", "tripod"] }
```
Returns a `CalibrationResultResponse` (see `docs/CALIBRATION_PROTOCOL.md`
for what determines accept/reject).

### `POST /v1/devices/{patient_id}/telemetry`
Append a telemetry event (grip changes, interlock trips, charging events, etc).
```json
{
  "patient_id": "P-1002",
  "timestamp": "2026-03-04T14:02:11Z",
  "event_type": "interlock_tripped",
  "payload": { "reason": "low_confidence" }
}
```

### `GET /v1/devices/{patient_id}/events?limit=50`
Returns the most recent telemetry/device events for the patient, most-recent last.

## Example session

```bash
uvicorn neuroflex.api.main:app --reload

curl -s http://localhost:8000/v1/devices/P-1002/status | jq
curl -s -X POST http://localhost:8000/v1/devices/P-1002/calibration/start \
  -H 'Content-Type: application/json' \
  -d '{"patient_id":"P-1002","cue_sequence":["power","pinch","tripod"]}' | jq
curl -s -X POST http://localhost:8000/v1/devices/P-1002/mode \
  -H 'Content-Type: application/json' \
  -d '{"patient_id":"P-1002","mode":"assisted"}' | jq
```
